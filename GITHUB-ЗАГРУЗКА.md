# Как загрузить обновлённый «Эхо» в SaTayouNy/EchoWeb

## Рекомендуемый вариант: GitHub Desktop (Windows)

1. В GitHub Desktop: **File → Clone repository → URL**. Вставь `https://github.com/SaTayouNy/EchoWeb` и выбери папку на компьютере.
2. Выбери **Current Branch → New Branch**. Назови ветку `feature/echo-analytics-metrica` и создай её от актуальной `main` (или от основной ветки репозитория).
3. Распакуй архив `EchoWeb-GitHub-ready.zip`. **Скопируй содержимое архива, не папку целиком**, в локальную папку клонированного репозитория. В случае конфликтов с уже существующими `src/`, `index.html` и другими файлами сначала проверь различия: эта сборка сделана из локального «Эхо» v10.28 и может отличаться от текущего `EchoWeb`.
4. **Не удаляй** существующие папки `docs/`, `.github/` и другую командную документацию. Если GitHub Desktop показывает удаление чужих файлов — отмени эти удаления.
5. Убедись, что `.env` и `dist/` **не появляются** в списке изменений. `.env.example` загружать можно.
6. В GitHub Desktop запиши Summary: `feat: integrate API, product analytics and Yandex Metrica`.
7. Нажми **Commit to feature/echo-analytics-metrica → Publish branch** (или Push origin).
8. Нажми **Create Pull Request** и отправь PR на проверку PM. После согласования можно слить ветку в `main`.

## Проверка перед коммитом

В папке клонированного проекта открой терминал и выполни:

```powershell
npm test
npm run build
```

Для локального запуска создай `.env` на основе `.env.example` (Windows PowerShell):

```powershell
Copy-Item .env.example .env
npm run dev
```

Локальный адрес: `http://localhost:5173/`. Яндекс Метрика **специально не отправляет визиты с localhost**. В `VITE_YANDEX_METRIKA_ID` уже указан счётчик **114072239**. Для реальной публикации укажи `VITE_ANALYTICS_ENV=production` в `.env`, выполни `npm run build` и опубликуй `dist/` на HTTPS-домене. Без `.env` при сборке счётчик отключён.

## Важно

- **Не загружай `.env`, токены и пароли.** Публичный ID Метрики не является секретом.
- `VITE_API_URL` пустой: приложение пока в демо-режиме, пока не задан настоящий адрес BE.
- Это подготовленные исходники, **не отправленный в GitHub коммит**. У ассистента нет подтверждённого доступа на запись в репозиторий.
- Из-за отсутствия доступа к текущей версии `EchoWeb` не подтверждена совместимость изменений с существующими файлами репозитория. Не заменяй всё без проверки diff.
