# Эхо — React + TypeScript + Vite

Это **основной сайт «Эхо»**, перенесённый из HTML/JavaScript-прототипа v10.28 в React-компоненты. Лендинга в этом проекте нет.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для сборки:

```bash
npm run build
npm run preview
```

## Структура

- `src/App.tsx` — состояние и маршрутизация экранов.
- `src/context.tsx` — контекст приложения.
- `src/pages/Movies.tsx` — главная, каталог, поиск, фильм и редактор рецензий.
- `src/pages/Profiles.tsx` — профили, предпочтения, публичные страницы авторов.
- `src/pages/Accounts.tsx` — демонстрационный вход и Эхо Studio.
- `src/components/UI.tsx` — переиспользуемые оценки, постеры, рецензии, списки фильмов.
- `src/data/content.json` — демонстрационные фильмы, оценки, авторы, рецензии.
- `src/styles.css` — исходные токены и стили Echo UI.
- `src/react.css` — раскладка React-компонентов.

## Важно о текущем функционале

Это фронтенд-прототип, **без сервера и базы данных**. Регистрация и вход имитируются локально, не являются настоящей аутентификацией. Не вводите реальные пароли. Черновики рецензий, предпочтения и лайки сохраняются в `localStorage` текущего браузера; модерация демонстрационная. Для рабочего сайта нужны серверная аутентификация, API, хранение данных, модерация и загрузка изображений на сервер.

## Замена репозитория movie-platform

1. Скачайте резервную копию текущего репозитория (`Code → Download ZIP`).
2. В веб-редакторе `github.dev/HalbertAsh/movie-platform` удалите **старые файлы**, которых нет в этом архиве, включая старые компоненты и `public`-ассеты. Не удаляйте `.git` при локальной работе.
3. Загрузите **содержимое** этого архива в корень репозитория, а не ZIP целиком.
4. Сделайте коммит.

**Не используйте старый `package-lock.json`** от предыдущего React-проекта: выполните `npm install` и сохраните сгенерированный новый lock-файл при локальной работе.

## GitHub Pages

В архиве есть workflow `.github/workflows/deploy.yml` для сборки Vite и публикации сайта. Чтобы он работал, в `Settings → Pages → Build and deployment → Source` выберите **GitHub Actions**. Публикация непосредственно из `main / (root)` для исходников Vite не подходит.
