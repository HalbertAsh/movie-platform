# Эхо — статус сценариев FE ↔ API

**Статусы:** «Проверено на моках» — UI вызывает ожидаемый маршрут с тестовым ответом. «Ждёт BE» — реальный контракт отсутствует. Реальные сквозные тесты не выполнялись, потому что URL тестового API не предоставлен.

| Сценарий | Статус | Примечание |
|---|---|---|
| Демо при пустом `VITE_API_URL` | Проверено | Сайт полностью открывается без сервера |
| Загрузка фильмов и деталей | Проверено на моках | `/v1/media`, `/v2/media/movie/{tmdbId}/details` |
| Рецензии и пагинация | Проверено на моках | `GET /v2/reviews` с `limit`, `offset`, `tmdbId` |
| Регистрация / вход | Проверено на моках | `/v1/auth/register`, `/v1/auth/login` |
| Токены, Bearer, refresh 401 | 19 тестов API-клиента | Контракт refresh требует подтверждения BE |
| Восстановление сессии | Проверено на моках | `GET /v1/me` |
| Профиль пользователя | Проверено на моках | `GET /v1/me/profile`, `GET /v1/users/{id}/profile` |
| Оценка без рецензии | Проверено на моках | `PUT /v2/me/ratings/movie/{tmdbId}` |
| Рецензия → модерация | Проверено на моках | PUT оценки, затем POST рецензии |
| Свои pending после перезагрузки | Ждёт BE | Нужен подтверждённый фильтр `mine/status` |
| Лайк / снятие лайка | Проверено на моках | PUT/DELETE с откатом при ошибке |
| Топ-5 фильмов | Проверено на моках | PUT/DELETE с лимитом 5 |
| Предпочтения режиссёров/актёров | Ждёт BE | Нужен TMDB ID и контракт |
| Редактирование профиля | Ждёт BE | Маршрут не предоставлен |
| Вход автора | Ждёт BE | Маршрут не предоставлен |
| Лайк автора | Ждёт BE | Маршрут не предоставлен |
| Авторский комментарий | Ждёт BE | Маршрут не предоставлен |
| Обработка сети/403/404/500/таймаута | Проверено на моках | Ошибка не ломает страницу |
| Реальные сквозные сценарии зрителя и автора | Не проверено | Нужны URL BE, Swagger, тестовые аккаунты |
| Отсутствие ошибок JS в демо и mock API | Проверено | Chromium/Playwright |
| Сохранение на сервере после перезагрузки | Не проверено | Требуется тестовый BE |

**Изменённые файлы:** `src/api.js`, `src/app.js`, `.env`, `.env.example`, `index.html`, `tools/config.mjs`, `tools/serve.mjs`, `tools/build.mjs`, `README.md`, `package.json`, `package-lock.json`. `src/styles.css` не изменялся. Требуется согласование правок вне `src/api.js` и `.env` с PM.
